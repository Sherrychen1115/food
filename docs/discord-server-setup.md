# Discord Server 設定步驟

> 這份文件教你:建立自己的 Discord Server、建立給 agent 用的頻道、拿到頻道編號 `CHANNEL_ID`、產生邀請連結給同組同學。
> 你的電腦是 **macOS**,所以快捷鍵都用 macOS 的寫法(`⌘` 就是 Command 鍵)。
> Discord 偶爾會改版,畫面上的字可能和這裡略有不同。找不到時,找意思最接近的選項,括號裡附了英文名稱方便你對照。
> 這份文件只講 Discord 網頁和 App 上的操作,**不需要寫任何程式**。

**名詞先說明**:

- **Server(伺服器)**:Discord 裡的一個「社群空間」,你是擁有者。
- **頻道**:Server 裡的一個聊天室。這個專案會有一個專門的頻道,同學在裡面傳食物照片,agent 只聽這一個頻道。
- **CHANNEL_ID(頻道編號)**:每個頻道都有的一串數字(約 18 到 19 位),程式靠它知道要聽哪一個頻道。它不是密碼,但也不要隨便貼在公開的地方。

---

## 0. 先準備

1. 你有一個 Discord 帳號,而且已經登入。
2. 用 **Discord App**(桌面版)或瀏覽器打開 https://discord.com/app 都可以。下面的步驟兩種都適用。

---

## 1. 建立你自己的 Server

1. 看畫面**最左邊**那一欄(一排圓形圖示)。拉到最下面,點那個綠色的 **`+`**(新增伺服器 / Add a Server)。
2. 跳出視窗後,點 **「自己建立」**(Create My Own)。
3. 下一頁問你這個 Server 是給誰用的,點 **「僅供我和我的朋友使用」**(For me and my friends)。
4. 在「伺服器名稱」欄位輸入名字,例如 `食物記錄測試`。圖示可以不放,跳過。
5. 點右下角的 **「建立」**(Create)。
6. 建好後,你會自動進到這個 Server。左上角是 Server 名稱,左邊中間是頻道清單,預設會有一個叫 `一般`(general)的文字頻道。

---

## 2. 打開「開發者模式」(為了複製頻道編號)

Discord 預設不讓你複製各種編號,要先打開開發者模式。這個只要做一次。

1. 看畫面**左下角**,你的頭像和名字旁邊有一個 **齒輪**(使用者設定 / User Settings),點它。(也可以按 `⌘` + `,`。)
2. 左邊選單往下找 **「進階」**(Advanced),點進去。
3. 找到 **「開發者模式」**(Developer Mode),把右邊的開關**打開**(變成綠色)。
4. 按右上角的 **`✕`** 或鍵盤 `Esc` 關掉設定。

---

## 3. 建立給 agent 用的頻道

1. 在左邊的頻道清單,找到 **「文字頻道」**(Text Channels)這個分類名稱。把滑鼠移到它上面,右邊會出現一個 **`+`**,點它。
2. 跳出「建立頻道」視窗。**頻道類型**選 **「文字」**(Text)(通常已經選好)。
3. 在「頻道名稱」輸入名字,例如 `food-log`(英文小寫比較不容易出問題;輸入中文也可以)。
4. **「私人頻道」**(Private Channel)的開關保持**關閉**。這樣同學加入 Server 後才看得到這個頻道。
5. 點右下角 **「建立頻道」**(Create Channel)。
6. 左邊頻道清單會出現新的頻道,點進去。畫面中間是聊天區,下方是輸入框。

---

## 4. 拿到 CHANNEL_ID

1. 在左邊頻道清單,找到剛剛建立的頻道(`food-log`)。
2. **在它上面按右鍵**(Mac 觸控板:兩指一起點一下;或按住 `control` 再點一下)。
3. 跳出選單,最下面附近有 **「複製頻道 ID」**(Copy Channel ID),點它。(找不到這一項,代表開發者模式沒打開,回到第 2 節重做。)
4. 這時候那串數字已經在你的剪貼簿裡了。打開一個**暫時的地方**(例如「備忘錄」App)按 `⌘` + `V` 貼上,會看到一串約 18 到 19 位的數字,例如 `1234567890123456789`。
5. 把它記下來,之後寫程式設定時會放進 `.env` 檔的 `CHANNEL_ID=`。

> **提醒**:`CHANNEL_ID` 不是密碼,貼給我(Claude)看沒問題。但**下一份文件要拿的 bot token 就絕對不行**,請看 `docs/discord-bot-setup.md`。

---

## 5. 產生邀請連結給同組同學

**先講風險**:agent 每處理一張照片,都會用掉**你自己的 Claude 額度**(見 `docs/architecture.md` 第 13 節)。誰能進這個頻道,誰就能耗你的額度。所以邀請連結要**設定到期時間和使用次數**,不要建立永久、無限次數的連結。

1. 點畫面**左上角**你的 **Server 名稱**(例如「食物記錄測試」),旁邊有一個小箭頭 `▾`。
2. 跳出選單,點 **「邀請其他人」**(Invite People)。
3. 跳出的視窗下方有一個連結(長得像 `https://discord.gg/xxxxxxx`)。在連結下面,點一行小字 **「編輯邀請連結」**(Edit invite link)。(有些版本是視窗右上角的**齒輪**。)
4. 設定:
   - **「邀請連結到期時間」**(Expire After)選 **7 天**(測試完就會失效)。
   - **「使用次數上限」**(Max Number of Uses)選一個接近同學人數的數字,例如 **10**。
   - **「授予臨時成員資格」**(Grant temporary membership)保持**關閉**。
5. 點 **「產生新連結」**(Generate a New Link)。
6. 點 **「複製」**(Copy),把連結貼給同組同學(例如傳到你們的 LINE 群組)。
7. 同學點連結後,在 Discord 按「接受邀請」(Accept Invite),就會進到你的 Server。

> 想收回連結:Server 名稱 `▾` → **「伺服器設定」**(Server Settings) → **「邀請」**(Invites),可以看到所有連結,在連結右邊按 `✕` 刪除。

---

## 6. 確認完成

- [ ] 我有一個自己的 Server,而且我是擁有者。
- [ ] Server 裡有一個文字頻道 `food-log`(或你取的名字)。
- [ ] 我已經複製了這個頻道的 `CHANNEL_ID`,並且暫時記在備忘錄。
- [ ] 同組同學用邀請連結進來了,他們能在左邊看到 `food-log` 頻道。
- [ ] 邀請連結有設定到期時間和使用次數。
